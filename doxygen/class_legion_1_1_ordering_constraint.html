Detailed Description

An ordering constraint specifies an ordering on index space dimensions as well as the special 'field' dimension. The earliest dimensions are assumed to be the most-rapidly changing in memory, therefore:

Array-of-structs (AOS): DIM_F is listed first Struct-of-arrays (SOA): DIM_F is listed last

Again users can specify multiple of these constraints to describe a partial order, but the common case will almost certainly be to specify a total order. Users can also specify whether or not the related constraints are contiguous with each other.
