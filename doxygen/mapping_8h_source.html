125 // Control Replication methods
126 // In general SPMD-style programming in Legion is wrong. If you find
127 // yourself writing SPMD-style code for large fractions of your program
128 // then you're probably doing something wrong. There are a few exceptions:
129 // 1. index attach/detach operations are collective and may need
130 // to do per-shard work
131 // 2. I/O in general often needs to do per-shard work
132 // 3. interaction with collective frameworks like MPI and NCCL
133 // 4. others?
134 // For these reasons we allow users to get access to sharding information
135 // Please, please, please be careful with how you use it
136 //------------------------------------------------------------------------
