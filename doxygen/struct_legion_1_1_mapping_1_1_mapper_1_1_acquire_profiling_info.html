Detailed Description

Report Profiling

If the mapper requested profiling information on this acquire operation, then this call will be invoked with the associated profiling data. You are always guaranteed to get at least one of these calls if the number of profiling requests is not empty even if there are no copies or fills performed in order to report the 'total_reports' to be expected. If the number of 'total_reports' is zero then the that means that no copies or fills were generated and this is in the only response that should be expected and it contains no other valid information.
