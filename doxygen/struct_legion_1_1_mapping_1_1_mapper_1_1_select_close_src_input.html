Detailed Description

Select Close Sources

The rank copy sources mapper call will be invoked whenever multiple physical instances can serve as the source for a copy aimed at the 'target' physical instance. The possible source instances are named in 'source_instances' and the mapper can specify a ranking in 'chosen_ranking'. Any instances not explicitly listed in the order will be used by the runtime in an undefined order.
