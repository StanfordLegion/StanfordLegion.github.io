Detailed Description

Select Release Sources

The select release sources call allows mappers to specify a 'chosen_ranking' for different 'source_instances' of a region when copying to a 'target' phsyical instance. The mapper can rank any or all of the source instances and any instances which are not ranked will be copied from in an unspecified order by the runtime until all the necessary fields in the target contain valid data.
